# Rendus PSV

Deposer ici les 8 fichiers PNG (ou WebP), un par configuration :

- `cfg-1.png` : Verticale haut (Decharge ouverte)
- `cfg-2.png` : Verticale bas (Decharge inversee)
- `cfg-3.png` : Horizontale (Decharge laterale)
- `cfg-4.png` : Coude 90 deg (haut puis horizontal)
- `cfg-5.png` : Collecteur (torche / systeme ferme)
- `cfg-6.png` : Col de cygne (double coude 180 deg)
- `cfg-7.png` : Laterale (Z), perpendiculaire a la ligne
- `cfg-8.png` : Incline 45 deg

Chaque fichier ne doit contenir que la geometrie 3D de la PSV et de sa
tuyauterie (pas de fleche de force, pas de label). Les fleches Fx/Fy/Fz
sont dessinees en SVG par-dessus l'image par l'application, avec les
valeurs reelles calculees pour chaque scenario.
